אין פריסה אוטומטית מהמאגר לקו. שינויים ב־AI ובקו החי דורשים אישור מנהל לפני הפעלה.

## עקרונות פיתוח

- סודות רק ב־Cloudflare Worker Secrets, ולעולם לא בקוד או בהיסטוריית Git.
- פעולות מנהל חייבות אימות נפרד ומוגבל, ללא מפתח בכתובת URL או בפרמטרי query.
- נתוני מתקשרים, הקלטות ותמלולים נשמרים מחוץ למאגר.
- מייבאים קוד חי רק לסביבת עבודה מקומית פרטית, בודקים ומסירים פרטים רגישים לפני כל פרסום.
