# סקרים וכתבות בחירות — שלוחה 1

מערכת נפרדת לקו 0794949476, שלוחה 1. תזמון הסריקה החיצונית נמצא ב־`.github/workflows/election-news.yml`.

## מה עושה הרכיב

- אוסף כתבות וסקרי בחירות מהמקורות הציבוריים הרשמיים של חדשות 12, חדשות 13, כאן, ערוץ 14 ו־i24NEWS.
- סקרי חדשות 13 שכבר אותרו נשמרים גם בקטלוג מזהי מקור ציבוריים (נבדק ב־17.10.2026), כדי שחסימה בדף לא תעצור את הטיפול בתור הקיים. הקטלוג אינו פיד חי.
- כללי ניגון המגבילים את פרופיל ההפצה מכובדים: נבחר רק פרופיל מותר, לרבות HLS או DASH ציבוריים לא מוצפנים. חסימה, DRM או פעולה לא מוכרת עדיין נדחים.
- אם שני מדורי חדשות 13 חסומים, נאספים גם סרטוני בחירות מהערוץ הרשמי שלהן ביוטיוב. זהות המפרסם נבדקת בפיד ובהורדה עצמה; אין שימוש בחשבון, cookies או תוכן מוגן.
- מפיק את האודיו המקורי מתוך המדיה הקיימת. אין יצירת קריינות או קול מלאכותי.
- מטפל גם בכמה סרטונים באותה כתבה ובשידורי HLS ארוכים יותר ממגבלת המקטעים של ה־Worker.
- ממיר ל־MP3 חד־ערוצי המתאים לטלפוניה, ובודק את משכו לפני ההעלאה.
- מנסה משיכה מאומתת דרך Cloudflare כאשר מקור רשמי חוסם את הסורק ב-GitHub. הממסר מוגבל לדפי המקורות ולממשקי המטא־נתונים שלהם.
- סורק את שנת הבחירות הנוכחית, ללא מגבלת 30 יום. פריטים שנכשלו נכנסים לניסיון חוזר; כתבות ללא מדיה נבדקות שוב אחרי שעה.
- מדווח בנפרד על כתבות ללא מדיה, תקלות מקור וקבצים שנדחו. כתבה טקסטואלית בלבד אינה הופכת לאודיו.
- אינו עוקף כניסה, מנוי או DRM. שידורים חיים ו־HLS מוצפן אינם נאספים.
- מוריד קבצים זמניים בסביבת הריצה ומוחק אותם בסיום; קובצי מדיה אינם נשמרים במאגר.

## חיבור ואבטחה

העלאה לקו מתבצעת דרך Worker בשם `election-news-ivr`. מפתח ימות המשיח נשמר רק בסודות של Cloudflare.
ה־workflow מקבל מ־GitHub אסימון OIDC קצר־חיים. ה־Worker מאמת חתימה מול מפתחות GitHub, קהל יעד, מזהה מאגר, ענף main ואת קובץ ה־workflow המדויק. משימות Pull Request אינן מורשות להעלות קבצים.
אין צורך להוסיף סודות ל־GitHub עבור מערכת זו.

הקבצים `worker.mjs`, `collector-auth.mjs` ו־`schema.sql` הם המקור של ה־Worker הנפרד; אין פריסה אוטומטית שלהם דרך ה־workflow הקיים של yemot-ai.

## תזמון והפעלה

- סריקה חיצונית אחת לשעה, בדקה 17, עם כפתור הפעלה ידני ב־Actions.
- הפעלה בעת שינוי קוד המערכת ב־main; ב־Pull Request רצות בדיקות בלבד.
- לכל ריצה תקציב של 540 שניות ועד 16 קבצים. המשך הפריטים יטופל בריצות הבאות.
- תזמון ה־Worker הקיים נשאר נפרד. נעילה ובדיקת הקובץ הקיים מונעות העלאות כפולות.

## בדיקות מקומיות

```bash
python -m unittest discover -s election-news -p 'test_*.py'
node --test election-news/*.test.mjs
```

בדיקות האבטחה מכסות אסימון חתום תקין ודחיית מאגר/ענף/workflow/חתימה שגויים או תפוגה. בדיקות המדיה מכסות חילוץ מקור, מניעת כפילויות, מגבלות השמעה, בחירת HLS, כתובות פנימיות וקטעי המשך.

## מגבלות שנותרות

זמינות תלויה בכך שהערוץ מפרסם מדיה ציבורית נתמכת. שינוי נגן או ממשק מקור עשוי לדרוש עדכון. קובץ אודיו גדול מ־24MiB, כשל בהורדה, או מדיה שאינה פתוחה לא יועלו. אין הבטחה שכל כתבה בכל ערוץ כוללת קובץ מקור שניתן לאסוף.
